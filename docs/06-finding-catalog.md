# 🚨 Finding Types Catalog

This document provides a comprehensive reference for every finding type generated by MEAT-GRINDER. Findings are
categorized by severity and include descriptions, source modules, default confidence levels, and remediation guidance.

---

## 📊 Severity Overview

| Severity        | Description                                                 | Typical Action      |
|-----------------|-------------------------------------------------------------|---------------------|
| 🔴 **CRITICAL** | Immediate exploitation risk, confirmed vulnerabilities      | Fix immediately     |
| 🟠 **HIGH**     | Significant security weakness, high exploitation likelihood | Fix within 7 days   |
| 🟡 **MEDIUM**   | Moderate risk, requires specific conditions to exploit      | Fix within 30 days  |
| 🟢 **LOW**      | Minor issue, defense-in-depth concern                       | Fix in next sprint  |
| 🔵 **INFO**     | Informational, no direct security impact                    | Review and document |

---

## 🔴 CRITICAL Severity

Findings that represent **immediate, exploitable risks** requiring urgent remediation.

### `EXPOSED_SENSITIVE_FILE`

- **Description:** Configuration file containing actual secrets (`.env`, `.git/config`, `wp-config.php`, etc.) is
  publicly accessible.
- **Source Module:** `SensitiveFileScanner`
- **Default Confidence:** `CONFIRMED`
- **Validation:** Regex-verified to contain actual secrets (DB passwords, API keys, private keys).
- **Remediation:** Remove file from web root, configure web server to deny access to dotfiles, rotate all exposed
  credentials immediately.

### `LEAKED_SECRET`

- **Description:** Secret discovered in a Git repository via Gitleaks (API keys, tokens, private keys).
- **Source Module:** `GitScanner`
- **Default Confidence:** `HIGH`
- **Validation:** Pattern-matched against 70+ secret rules.
- **Remediation:** Rotate the secret immediately, remove from Git history using `git filter-repo` or BFG, add to
  `.gitignore`.

### `DEEP_CODE_SECRET (VERIFIED)`

- **Description:** Live, actively valid secret discovered in code via TruffleHog's verification process.
- **Source Module:** `SASTScanner`
- **Default Confidence:** `CONFIRMED`
- **Validation:** TruffleHog actively tests the secret against the provider's API.
- **Remediation:** **IMMEDIATE ROTATION REQUIRED.** This is a live credential. Revoke and regenerate.

### `ANDROID_DEBUGGABLE`

- **Description:** Android application has `android:debuggable="true"` in production manifest.
- **Source Module:** `MobileScanner`
- **Default Confidence:** `CONFIRMED`
- **Validation:** Parsed from `AndroidManifest.xml` via `apktool`.
- **Remediation:** Remove `android:debuggable="true"` from production builds. Use build variants.

### `TLS_CERT_EXPIRED`

- **Description:** TLS certificate has expired (past `notAfter` date).
- **Source Module:** `TLSScanner`
- **Default Confidence:** `CONFIRMED`
- **Validation:** Direct certificate inspection via SSL socket.
- **Remediation:** Renew certificate via Let's Encrypt or commercial CA. Set up auto-renewal.

### `VULNERABLE_DEPENDENCY` (Critical CVE)

- **Description:** Dependency contains a critical-severity CVE (CVSS 9.0+).
- **Source Module:** `SBOMScanner`
- **Default Confidence:** `HIGH`
- **Validation:** Matched against Trivy's vulnerability database.
- **Remediation:** Upgrade to patched version immediately. Review changelog for breaking changes.

### `SUBDOMAIN_TAKEOVER_VULNERABLE`

- **Description:** Subdomain is actively claimable via dangling CNAME to a cloud provider (AWS S3, GitHub Pages, Heroku,
  etc.).
- **Source Module:** `TakeoverVerifier`
- **Default Confidence:** `CONFIRMED`
- **Validation:** HTTP response matches known provider takeover fingerprints (e.g., "NoSuchBucket").
- **Remediation:** Remove dangling CNAME record, or claim the resource and secure it.

## 🟠 HIGH Severity

Findings that represent **significant security weaknesses** with high exploitation likelihood.

### `HARDCODED_SECRET_IN_WEB_FILE`

- **Description:** Secret (AWS key, Stripe token, GitHub PAT, JWT) found in JavaScript or HTML source.
- **Source Module:** `WebContentScanner`, `JSRecursiveScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Move secrets to server-side environment variables. Use backend proxies for API calls.

### `ANDROID_ALLOW_BACKUP`

- **Description:** Android app allows data extraction via `adb backup`.
- **Source Module:** `MobileScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Set `android:allowBackup="false"` in manifest.

### `ANDROID_EXPORTED_COMPONENTS`

- **Description:** Activities, services, or receivers are exported without permission checks.
- **Source Module:** `MobileScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Add `android:exported="false"` or require explicit permissions.

### `ANDROID_CLEARTEXT_ALLOWED`

- **Description:** App permits unencrypted HTTP traffic via `network_security_config.xml`.
- **Source Module:** `MobileScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Remove `cleartextTrafficPermitted="true"`. Enforce HTTPS.

### `IOS_ATS_BYPASS`

- **Description:** iOS app disables App Transport Security globally (`NSAllowsArbitraryLoads=true`).
- **Source Module:** `MobileScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Remove the key or set to `false`. Use exception domains if needed.

### `IOS_PLIST_SECRET`

- **Description:** Hardcoded API keys or credentials found in `Info.plist`.
- **Source Module:** `MobileScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Move secrets to Keychain or server-side configuration.

### `CLOUD_ASSET_DISCOVERED` (Public)

- **Description:** Cloud storage bucket (S3, Azure Blob, GCS) is publicly readable/writable.
- **Source Module:** `CloudScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Set bucket policy to private. Review access logs for unauthorized access.

### `OPENAPI_EXPOSED`

- **Description:** Swagger/OpenAPI documentation is publicly accessible.
- **Source Module:** `APIScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Move API docs behind authentication or remove from production.

### `GRAPHQL_INTROSPECTION_ENABLED`

- **Description:** GraphQL endpoint allows schema introspection queries.
- **Source Module:** `APIScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Disable introspection in production via server configuration.

### `WEAK_SPF`

- **Description:** SPF record uses `+all` or lacks `all` directive, allowing any sender.
- **Source Module:** `DNSScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Update SPF to `v=spf1 include:_spf.google.com ~all` (or similar).

### `DANGLING_CNAME`

- **Description:** CNAME record points to a cloud service that no longer exists (potential takeover).
- **Source Module:** `DNSScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Remove the CNAME record or claim the resource.

### `TLS_CERT_EXPIRING_SOON`

- **Description:** TLS certificate expires within 30 days.
- **Source Module:** `TLSScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Renew certificate before expiry.

### `TLS_HOSTNAME_MISMATCH`

- **Description:** TLS certificate does not match the requested hostname.
- **Source Module:** `TLSScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Obtain a certificate with the correct SAN or fix DNS configuration.

### `TLS_WEAK_PROTOCOL`

- **Description:** Server supports TLSv1.0, TLSv1.1, SSLv2, or SSLv3.
- **Source Module:** `TLSScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Disable weak protocols. Require TLSv1.2 or TLSv1.3.

### `EOL_OS_OR_SERVICE`

- **Description:** End-of-Life operating system or service detected.
- **Source Module:** `OSRecon`
- **Default Confidence:** `HIGH`
- **Remediation:** Upgrade to supported version.

### `OUTDATED_WEBSERVER`

- **Description:** Web server version is outdated (Apache, Nginx, IIS).
- **Source Module:** `HeaderAnalyzer`
- **Default Confidence:** `HIGH`
- **Remediation:** Update web server to latest stable version.

### `IAC_MISCONFIGURATION`

- **Description:** Infrastructure as Code contains security misconfigurations.
- **Source Module:** `IaCScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Fix Checkov-detected issues (public S3, open security groups, etc.).

### `DOCKERFILE_SECRET_LEAK`

- **Description:** Secrets hardcoded in Dockerfile (ENV, ARG).
- **Source Module:** `IaCScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Use Docker secrets or build-time args. Never bake secrets into images.

### `TERRAFORM_PUBLIC_S3`

- **Description:** Terraform defines a public S3 bucket.
- **Source Module:** `IaCScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Set `acl = "private"` or use bucket policies.

### `TERRAFORM_OPEN_SECURITY_GROUP`

- **Description:** Security group allows `0.0.0.0/0` ingress.
- **Source Module:** `IaCScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Restrict CIDR to known IP ranges.

### `K8S_PRIVILEGED_POD`

- **Description:** Kubernetes pod runs in privileged mode.
- **Source Module:** `IaCScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Remove `privileged: true` from pod spec.

### `NUCLEI_VULN/MISCONFIG`

- **Description:** Vulnerability or misconfiguration detected by Nuclei templates.
- **Source Module:** `NucleiScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Follow Nuclei template remediation guidance.

### `HISTORICAL_SECRET_LEAK`

- **Description:** Secrets found in Wayback Machine archives (deleted but still accessible).
- **Source Module:** `WaybackScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Rotate exposed credentials. Request archive removal if possible.

### `DEEP_JS_SECRET`

- **Description:** Secrets found in external/linked JavaScript files (Depth 2 crawl).
- **Source Module:** `JSRecursiveScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Move secrets to server-side. Remove from JS bundles.

### `GITHUB_CODE_LEAK`

- **Description:** Target data with secrets found in public GitHub repositories.
- **Source Module:** `PasteMonitor`
- **Default Confidence:** `HIGH`
- **Remediation:** Rotate secrets, remove from public repos, add to `.gitignore`.

### `PASTE_SITE_LEAK`

- **Description:** Target data with secrets found on paste sites (Pastebin, Ghostbin, etc.).
- **Source Module:** `PasteMonitor`
- **Default Confidence:** `HIGH`
- **Remediation:** Rotate exposed credentials, request paste removal.

### `SOURCE_MAP_SECRET`

- **Description:** Sensitive data found in JavaScript source maps.
- **Source Module:** `SourceMapScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Remove source maps from production. Use build-time obfuscation.

## 🟡 MEDIUM Severity

Findings that represent **moderate risks** requiring specific conditions to exploit.

### `EXPOSED_FILE`

- **Description:** File exists but no obvious secrets detected.
- **Source Module:** `SensitiveFileScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Review file contents, remove if unnecessary.

### `PROTECTED_SENSITIVE_FILE`

- **Description:** Sensitive file exists but returns 403 Forbidden (e.g., `.git` directory).
- **Source Module:** `SensitiveFileScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Ensure web server blocks access to sensitive directories.

### `MISSING_HSTS`

- **Description:** No `Strict-Transport-Security` header.
- **Source Module:** `HeaderAnalyzer`
- **Default Confidence:** `HIGH`
- **Remediation:** Add `Strict-Transport-Security: max-age=31536000; includeSubDomains`.

### `MISSING_CLICKJACKING_PROTECTION`

- **Description:** No `X-Frame-Options` or `Content-Security-Policy` header.
- **Source Module:** `HeaderAnalyzer`
- **Default Confidence:** `HIGH`
- **Remediation:** Add `X-Frame-Options: DENY` or CSP `frame-ancestors 'none'`.

### `ANDROID_CUSTOM_URL_SCHEME`

- **Description:** App registers custom URL schemes (deep link attack surface).
- **Source Module:** `MobileScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Validate all deep link inputs. Use App Links (Android) or Universal Links (iOS).

### `ANDROID_DANGEROUS_PERMISSIONS`

- **Description:** App requests dangerous permissions (CAMERA, SMS, CONTACTS).
- **Source Module:** `MobileScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Request only necessary permissions. Use runtime permission requests.

### `IOS_URL_SCHEMES`

- **Description:** iOS app registers custom URL schemes.
- **Source Module:** `MobileScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Validate inputs. Prefer Universal Links.

### `IOS_ATS_EXCEPTION`

- **Description:** Specific domain allows insecure HTTP loads.
- **Source Module:** `MobileScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Enforce HTTPS for all domains.

### `CMS_VERSION_EXPOSED`

- **Description:** CMS version revealed via `<meta name="generator">` tag.
- **Source Module:** `HTMLMetadataExtractor`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Remove or obfuscate generator meta tag.

### `HTML_COMMENT_LEAK` (Sensitive)

- **Description:** HTML comments contain sensitive information (API keys, internal URLs).
- **Source Module:** `HTMLMetadataExtractor`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Remove sensitive comments from production HTML.

### `HIDDEN_FORM_FIELD`

- **Description:** Hidden form fields contain sensitive data (CSRF tokens, API keys).
- **Source Module:** `HTMLMetadataExtractor`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Ensure hidden fields don't expose secrets.

### `API_ENDPOINT_IN_LINK`

- **Description:** API paths discovered in `<link>` tags.
- **Source Module:** `HTMLMetadataExtractor`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Review API endpoint exposure.

### `GRAPHQL_ENDPOINT`

- **Description:** GraphQL endpoint discovered.
- **Source Module:** `APIScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Ensure proper authentication and rate limiting.

### `WEAK_DMARC`

- **Description:** DMARC policy is set to `none` (no enforcement).
- **Source Module:** `DNSScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Set `p=quarantine` or `p=reject`.

### `MISSING_DMARC`

- **Description:** No DMARC record found.
- **Source Module:** `DNSScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Add DMARC record: `v=DMARC1; p=reject; rua=mailto:dmarc@domain.com`.

### `MX_MISCONFIGURATION`

- **Description:** MX record points to localhost or invalid host.
- **Source Module:** `DNSScanner`
- **Default Confidence:** `HIGH`
- **Remediation:** Fix MX record to point to valid mail server.

### `TLS_SELF_SIGNED`

- **Description:** TLS certificate is self-signed.
- **Source Module:** `TLSScanner`
- **Default Confidence:** `CONFIRMED`
- **Remediation:** Obtain certificate from trusted CA.

### `DOCKERFILE_RUNNING_AS_ROOT`

- **Description:** Dockerfile lacks `USER` directive (runs as root).
- **Source Module:** `IaCScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Add `USER nonroot` directive.

### `K8S_HOSTPATH_MOUNT`

- **Description:** Kubernetes pod mounts host filesystem.
- **Source Module:** `IaCScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Use PersistentVolumeClaims instead of hostPath.

### `VULNERABLE_DEPENDENCY` (Medium)

- **Description:** Dependency contains a medium-severity CVE (CVSS 4.0-8.9).
- **Source Module:** `SBOMScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Plan upgrade to patched version.

### `SOCIAL_MEDIA_CONTACT`

- **Description:** Social media profiles found via WHOIS/contact OSINT.
- **Source Module:** `WhoisContactOSINT`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Review for information disclosure.

### `PASTE_SITE_MENTION`

- **Description:** Target domain mentioned on paste sites (no secrets detected).
- **Source Module:** `PasteMonitor`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Review paste content for context.

### `SOURCE_MAP_EXPOSED`

- **Description:** JavaScript source map publicly accessible.
- **Source Module:** `SourceMapScanner`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Remove source maps from production builds.

### `ADMIN_PANEL_DISCOVERED`

- **Description:** Admin panel or management interface found.
- **Source Module:** `AdminDiscovery`
- **Default Confidence:** `MEDIUM`
- **Remediation:** Ensure strong authentication and IP whitelisting.

## 🧠 AI-Generated Findings

Findings generated by the AI modules (`AIAnalyzer`, `AIReconHunter`).

### `AI_GENERATED_ENDPOINT`

- **Description:** Endpoint discovered via AI-generated context-aware wordlist.
- **Source Module:** `AIReconHunter`
- **Default Confidence:** `MEDIUM`
- **Severity:** `HIGH` (if 200/500) or `MEDIUM` (if 401/403/405)

### `AI_LOGIC_ATTACK_SUGGESTION`

- **Description:** Business logic attack suggested by AI based on API analysis.
- **Source Module:** `AIReconHunter`
- **Default Confidence:** `MEDIUM`
- **Severity:** `MEDIUM`

### `AI_ATTACK_PATH`

- **Description:** Multi-step attack path chained by AI from isolated findings.
- **Source Module:** `AIReconHunter`
- **Default Confidence:** `MEDIUM`
- **Severity:** `CRITICAL` (Easy), `HIGH` (Medium), `MEDIUM` (Hard)

### `ANONYMOUS_FTP_ACCESS` (CRITICAL)

- **Description:** FTP service allows anonymous login with directory listing access.
- **Source Module:** `FTPAnonymousChecker`
- **Default Confidence:** `CONFIRMED`
- **Validation:** Actively tested with `anonymous`/`anonymous` credentials.
- **Remediation:** Disable anonymous FTP access or restrict to read-only with no sensitive directories.

## 📌 Notes

1. **Confidence Levels:** Findings are assigned confidence levels (`CONFIRMED`, `HIGH`, `MEDIUM`, `LOW`, `INFO`) based
   on validation rigor. `CONFIRMED` means the finding was actively verified (e.g., secret tested against API).

2. **Severity Inheritance:** Some findings inherit severity from external tools (e.g., Nuclei templates, Trivy CVEs).

3. **AI-Enhanced Findings:** When `AIAnalyzer` is enabled, CRITICAL and HIGH findings are enhanced with business impact
   and remediation steps appended to the `details` field.

4. **Deduplication:** The `InsightFilter` module deduplicates findings using SHA256 fingerprints. Duplicate findings
   increment the `occurrences` counter instead of creating new rows.

5. **Diff Mode:** When running with `--diff`, only findings with `first_seen` after the last scan timestamp are included
   in the report.
